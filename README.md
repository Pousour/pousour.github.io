# pousour.github.io

Site GitHub Pages personnel (2021) : une page de création artistique et quelques mini-projets web.

## Contenu

- **Page d'accueil** (`index.html`) : création artistique, une ambiance de pluie animée en JavaScript sur des photos de villes (Paris, New York, Tokyo, Toronto, Singapour), avec un son de pluie. À voir en plein écran (F11).
- **`jeu2d/`** : jeu de plateforme en Phaser.
- **`harmonica/`** : un harmonica qui joue un morceau et affiche ses notes.
- **`Estats/`** : E-Stats, une maquette de site de statistiques e-sport (CS, Fortnite, League of Legends, Rocket League, Smash, Valorant).
- **`countdownTimer/`** : un compte à rebours.

## Voir le site

Publié par GitHub Pages à l'adresse https://pousour.github.io. En local :

```bash
python3 -m http.server 8000
```
